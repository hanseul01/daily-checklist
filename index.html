GitHub 토큰 연결

할 일은 비공개 저장소 hanseul01/daily-checklist-data에 저장됩니다. 이 기기에서 그 저장소를 읽고 쓰려면 토큰이 한 번 필요합니다.

  1. 토큰 만들기 페이지를 엽니다.
  2. Repository access에서 Only select repositories → daily-checklist-data만 고릅니다.
  3. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다.
  4. 맨 아래 Generate token을 누르고, 나온 토큰(github_pat_로 시작)을 복사해 아래에 붙여 넣습니다.
